Markdown 使用方法

Markdown 是一种轻量级标记语言，常用于格式化文本。它易于阅读和编写，并且可以转换为有效的 HTML 文档。以下是 Markdown 的基本语法和使用方法。

标题

使用 # 符号来创建标题。# 的数量表示标题的级别。

段落和换行

段落由一个或多个连续的文本行组成，段落之间需要空一行。

要在 Markdown 中换行，可以在行尾添加两个空格，或者使用 <br> 标签。

强调

使用 * 或 _ 来表示斜体，使用 ** 或 __ 来表示粗体。

列表

无序列表

使用 -、+ 或 * 来创建无序列表。

有序列表

使用数字加点来创建有序列表。

链接和图片

链接

使用 [文本](URL) 来创建链接。

图片

使用 ![替代文本](图片URL) 来插入图片。

代码

行内代码

使用 ` 包裹行内代码。

代码块

使用 包裹多行代码块。

引用

使用 > 来创建引用。

表格

使用 | 和 - 来创建表格。

内嵌 HTML

Markdown 支持内嵌 HTML 标签。

数学符号及排版

希腊字母

  • 小写字母

    • α \alpha
    • β \beta
    • γ \gamma
    • δ \delta
    • ϵ \epsilon
    • ζ \zeta
    • η \eta
    • θ \theta
    • ι \iota
    • κ \kappa
    • λ \lambda
    • μ \mu
    • ν \nu
    • ξ \xi
    • π \pi
    • ρ \rho
    • σ \sigma
    • τ \tau
    • υ \upsilon
    • ϕ \phi
    • χ \chi
    • ψ \psi
    • ω \omega

  • 大写字母

    • Γ \Gamma
    • Δ \Delta
    • Θ \Theta
    • Λ \Lambda
    • Ξ \Xi
    • Π \Pi
    • Σ \Sigma
    • Υ \Upsilon
    • Φ \Phi
    • Ψ \Psi
    • Ω \Omega

运算符

  • 基本运算
    • + +
    • − -
    • × \times
    • ÷ \div
    • ⋅ \cdot
    • ± \pm
    • ∓ \mp
  • 关系运算符
    • = =
    • ≠ \neq
    • < <
    • > >
    • ≤ \leq
    • ≥ \geq
    • ≈ \approx
    • ≡ \equiv
    • ∝ \propto
  • 集合运算符
    • ∈ \in
    • ∉ \notin
    • ⊂ \subset
    • ⊆ \subseteq
    • ⊃ \supset
    • ⊇ \supseteq
    • ∪ \cup
    • ∩ \cap
    • ∅ \emptyset
  • 逻辑运算符
    • ∧ \land
    • ∨ \lor
    • ¬ \lnot
    • ⇒ \Rightarrow
    • ⇔ \Leftrightarrow
  • 几何关系
    • ∥ \parallel
    • ⊥\perp

上下标

  • 上标

    • x2 x^2
    • ex+y e^{x+y}

  • 下标

    • x1 x_1
    • xi,j x_{i,j}

分式与根式

  • 分式

    • ab \frac{a}{b}
    • ab \dfrac{a}{b}

  • 根式

    • x \sqrt{x}
    • xn \sqrt[n]{x}

积分与求和

  • 积分

    • ∫ \int
    • ∫ab \int_a^b
    • ∬ \iint
    • ∭ \iiint

  • 求和

    • ∑ \sum
    • ∑i=1n \sum_{i=1}^n

极限与导数

  • 极限

    • lim \lim
    • limx→∞ \lim_{x \to \infty}

  • 导数

    • dydx \frac{dy}{dx}
    • ∂f∂x \frac{\partial f}{\partial x}

矩阵与行列式

  • 矩阵

    • abcd \begin{matrix} a & b \\ c & d \end{matrix}
    • (abcd) \begin{pmatrix} a & b \\ c & d \end{pmatrix}
    • [abcd] \begin{bmatrix} a & b \\ c & d \end{bmatrix}

  • 行列式

    • |abcd| \begin{vmatrix} a & b \\ c & d \end{vmatrix}

其他符号

  • 箭头

    • → \rightarrow
    • ← \leftarrow
    • ⇒ \Rightarrow
    • ⇐ \Leftarrow
    • ↔ \leftrightarrow
    • ⇔\leftrightarrow

  • 点

    • ⋅ \cdot
    • ⋯ \cdots
    • ⋮ \vdots
    • ⋱ \ddots

  • 括号

    • () ( )
    • [] [ ]
    • {} \{ \}
    • ⟨⟩ \langle \rangle

  • 其他

    • ∞ \infty
    • ∇ \nabla
    • ∂ \partial
    • ℏ \hbar
